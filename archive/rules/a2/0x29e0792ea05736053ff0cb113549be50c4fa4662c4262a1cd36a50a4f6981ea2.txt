This market will resolve to "Yes" if the next Anthropic Claude Fable model (5.2+) added to the Arena.AI Leaderboard (https://arena.ai/leaderboard/text/overall-no-style-control) holds a rank within the specified top ranks when the table under the "Leaderboard" tab is checked at 12:00 PM ET on the calendar date following the date on which it first appears on the leaderboard. Otherwise, this market will resolve to "No".

A qualifying model must have a name or model identifier that includes "Fable" and be designated as version 5.2 or higher, regardless of capitalization or surrounding prefixes, suffixes, dates, or descriptors. For example, a version 5.2 or higher named in the same manner as Claude Fable 5 or Claude Fable 5.1 would qualify, including a new whole-number generation such as Claude Fable 6, while models whose name does not include "Fable" or which retain a version designation below 5.2, such as Claude Fable 5.1 or Claude Mythos 5.1, will not qualify.

Results from the "Rank" column under the "Text Arena | Overall" Leaderboard tab at https://arena.ai/leaderboard/text/overall-no-style-control with style control off (Adjustments: None), in the "Models" view, and with no other filters applied will be used to resolve this market. A model debuts within the specified top ranks if its displayed rank at the check time is equal to or better than the specified rank (for example, a displayed rank of 4 is within the top 5 and the top 10). This market will resolve solely based on the specified rank in the Rank column of the leaderboard, regardless of the model's score, rank spread or confidence intervals, ranks shown under other adjustments, filters, or categories, or any underlying granular or unrounded data presented elsewhere.

A model marked "AutoEval" will not be considered added to the leaderboard. A model is considered to first appear on the leaderboard on the first calendar date (ET) on which it is displayed with a rank and without the "AutoEval" label; only such ranks will be considered. An entry listed under a preliminary, code, or placeholder name is considered newly added on the first date it is displayed under a name satisfying the model specification clause above; a renamed entry's first appearance under a qualifying name counts as its addition to the leaderboard. Each separately listed entry, including reasoning or thinking-level variants of the same model, is a distinct model for the purposes of this market, and the first qualifying entry added governs resolution.

If multiple qualifying models are added to the leaderboard on the same calendar date (ET), the highest-ranking model will be used for resolution. Models added to the leaderboard on the calendar date following the initial qualifying model's first appearance will not be considered. If a qualifying model is not displayed on the leaderboard at 12:00 PM ET on the calendar date following its first appearance, that appearance will not qualify; if the model is subsequently displayed again, the date on which it reappears will be treated as a new first appearance.

A qualifying model must be newly added to the Arena.AI Leaderboard. Whether the model was previously released, publicly accessible, in beta, or otherwise available before appearing on the leaderboard is irrelevant for this market.

The resolution source for this market is the Arena.AI Leaderboard found at https://arena.ai/leaderboard/text/overall-no-style-control. If the leaderboard's URL, tab names, or control labels change, the equivalent default Text Overall view with style control disabled and no filters applied on arena.ai constitutes the same resolution source; such changes do not make the source unavailable. If this resolution source is unavailable at 12:00 PM ET on the calendar date following the date on which the qualifying model first appears on the leaderboard, this market will resolve based on the first subsequent instance at which the model's rank becomes available on the leaderboard. If it remains unavailable through the end of the seventh day after the qualifying model first appears on the leaderboard or if no qualifying model is added to the leaderboard by June 30, 2027, 11:59 PM ET, this market will resolve to "No".
